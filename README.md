# Yan and Yang

An interactive, watercolor inspired wedding invitation for Yan and Yang. The experience opens with a field of animated butterflies, then reveals the ceremony details, attire guide, wedding notes, entourage, and closing message.

[View the live invitation](https://yan-and-yang.vercel.app)

## Highlights

* Animated butterfly entrance with responsive placement and flight paths
* Scroll based floral and text reveals
* Ceremony, reception, attire, RSVP, and entourage details
* Responsive layouts for desktop and mobile screens
* Local font and image assets for a consistent visual presentation
* Semantic sections, reduced motion support, and keyboard accessible controls

## Built with

* React 19
* TypeScript
* Vite
* CSS animations and responsive styling

## Local development

Install the dependencies and start the development server:

```bash
npm install
npm run dev
```

Vite will print the local URL in the terminal.

## Available scripts

```bash
npm run dev      # Start the development server
npm run build    # Type check and create a production build
npm run lint     # Run oxlint
npm run preview  # Preview the production build locally
```

## Deployment

The site is deployed on Vercel. A production build creates the `dist` directory, which can also be served by any static hosting provider.
